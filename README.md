# 3D 沙盒 - 随意拖拽生成几何体

这是一个基于 Three.js 的 3D 创作工具，支持：

- 多种几何体（立方体、球体、圆环等）
- 创造模式 / 骨架模式
- 对称放置、吸附表面/线段
- 随机旋转/缩放
- 导出 OBJ 文件

## 🎮 在线体验

点击这里打开：**[https://bandrage.github.io/randomshapes/](https://bandrage.github.io/randomshapes/)**

## 📦 本地运行

1. 克隆本仓库
2. 直接在浏览器打开 `index.html`

## 🛠️ 操作说明

- **Tab** 切换普通/创造模式
- **A/D** 缩放预览物体
- **R** 随机缩放/旋转（需勾选选项）
- **右键拖拽** 删除物体（创造模式下）
